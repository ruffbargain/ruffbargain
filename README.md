# RuffBargain: how to run it for free

## Add a deal
Open `deals.js`, copy one deal block, change the fields, save. Expired deals hide automatically.

## Put it online (free)
1. Create a free GitHub account and a new repo; upload these files.
2. Create a free Cloudflare Pages account (or Netlify / GitHub Pages), connect the repo, deploy. No build command needed.
3. In the host's settings, add custom domain `ruffbargain.com` and update the domain's DNS as it instructs.

## Before you launch
- Replace the SAMPLE deals and the placeholder `#` links.
- Paste your email service's form code into the Newsletter section of `index.html`.
- Write the Disclosure, Privacy and About pages.
- Apply to affiliate programs and use your own links in `deals.js`.
